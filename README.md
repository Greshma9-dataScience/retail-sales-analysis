# retail-sales-analysis
Retail Sales Analysis Using SQL

Project Overview

This project analyzes retail sales data to understand revenue, profit, product performance, monthly sales, and city-wise sales.

Tools Used

- MySQL
- SQL
- GitHub

Dataset

The project uses a fictional dataset containing 10 retail orders from January to March 2026.

SQL Concepts Used

- SELECT and ORDER BY
- Aggregate functions: SUM and COUNT
- GROUP BY
- Calculated columns
- Date-based analysis

Business Questions

1. How many orders were recorded?
2. What is the total sales revenue?
3. What is the total profit?
4. Which product category generates the most revenue?
5. How does revenue change month by month?
6. Which products sell the most units?
7. Which city generates the highest revenue?

Project Objective

To practice SQL and develop business insights from retail sales data.

Note

This is a practice project using fictional data. Query results should be verified in MySQL Workbench before presenting the findings as completed analysis.
